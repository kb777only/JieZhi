# JieZhi generated brand concepts

This set explores the product's core idea: the desktop Host borrows local AI
intelligence from the connected phone Client.

- `jiezhi-logo-brain-transfer.png` — complete phone-to-desktop borrowing mark
- `jiezhi-host-icon.png` — Host receiving the borrowed brain
- `jiezhi-client-icon.png` — Client lending the brain

Palette: cobalt `#386BFF`, warm orange `#FF974E`.

These are transparent PNG concept assets generated with OpenAI ImageGen. They
do not replace the existing production SVG or Android launcher drawable.

## Gradient 3D set

- `jiezhi-logo-usb-thoughts-v2.png` — smartphone brain sending thought bubbles
  through a USB cable to the PC
- `jiezhi-host-icon-v2.png` — Host receiving thought bubbles from the cable
- `jiezhi-client-icon-v2.png` — Client phone lending its internal intelligence

This second set intentionally uses rich cobalt, indigo, violet, orange, and gold
gradients with glossy dimensional rendering rather than minimal flat geometry.

## Closed USB thought-flow set

- `jiezhi-logo-usb-thoughts-v3.png` — continuous brain-to-phone-port-to-cable-to-PC flow
- `jiezhi-host-icon-v3.png` — thoughts stay inside the cable until entering the Host
- `jiezhi-client-icon-v3.png` — the brain feeds directly into the phone USB port

Version 3 removes all open-air transfer bubbles. Inter-device thought bubbles
remain visibly enclosed by the USB cable from connector to connector.
